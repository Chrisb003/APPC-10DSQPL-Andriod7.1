Tablet Dashboard

Tablets on USB

A tablet plugged into this computer's USB port can be set up for the network in one go: remote management and network debugging are switched on, this computer is allowed on the tablet for good (no "Allow debugging?" when it connects over the network), and the tablet is added to the list by its network address. Needs firmware N1.7.

APK library

Upload an APK once, then install it on one or more tablets (existing apps are updated, their data is kept).

Firmware

Upload a firmware image once, then install it on one or more tablets at the same time. Each tablet needs its SD card in: the image is copied to the card, checked, and installed from there. (Images can also be copied straight into the "firmware" folder of the dashboard's data folder.)
